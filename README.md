# Portfolio web developer demos

Five standalone responsive website projects built with:

- semantic HTML5
- modern CSS3
- vanilla JavaScript ES6+
- responsive layouts
- interactive UI without frameworks
- SEO basics: page titles, meta descriptions and descriptive image alt text

## Projects

1. `01-atelier-cafe` - restaurant landing page with filterable menu and booking summary.
2. `02-pulse-studio` - fitness studio website with weekly class planner.
3. `03-nova-analytics` - responsive SaaS dashboard with search, filters and chart rendering.
4. `04-northline-travel` - travel landing page with itinerary cost estimator.
5. `05-luma-chair` - ecommerce product page with price configurator.
